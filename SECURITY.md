# Política de Seguridad (SECURITY.md)

FastTok toma la seguridad de la información muy en serio. Este documento explica cómo reportar de manera responsable y confidencial cualquier vulnerabilidad que encuentres en el proyecto.

## Versiones Soportadas

Actualmente, solo se proporcionan actualizaciones de seguridad para la última versión de producción:

| Versión | Soportada |
| ------- | --------- |
| 1.x.x   | ✅ Sí      |
| < 1.0   | ❌ No      |

## Reportar una Vulnerabilidad

**Por favor, NO abras un issue público en GitHub para reportar una vulnerabilidad de seguridad.**

Si descubres un problema de seguridad en este repositorio, te solicitamos que lo reportes de forma confidencial siguiendo estos pasos:

1. Envía un correo electrónico a nuestro correo de contacto de seguridad: [security@fasttok.lat](mailto:security@fasttok.lat) (o al correo configurado en tu variable `CONTACT_EMAIL`).
2. Describe detalladamente la vulnerabilidad, incluyendo:
   - Una descripción del problema.
   - Pasos detallados para reproducir el fallo (código de prueba, capturas de pantalla o peticiones HTTP de muestra).
   - El impacto potencial del problema.

## Nuestro Compromiso

Una vez recibido tu reporte:
- Responderemos en un plazo máximo de 48 horas confirmando la recepción del mismo.
- Trabajaremos en conjunto para validar y mitigar el fallo lo antes posible.
- Te mantendremos informado sobre el progreso de la solución y te daremos el crédito correspondiente una vez liberado el parche público (si así lo deseas).
